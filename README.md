# ClassTrack

ClassTrack is a browser-based **schedule analyzer & productivity dashboard**.

## What it does
- Analyzes a pasted class schedule
- Shows time spent per subject
- Finds free study blocks
- Detects schedule conflicts
- Provides a weekly workload balance / health score

## Tech stack
- React
- Tailwind CSS
- Recharts

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
